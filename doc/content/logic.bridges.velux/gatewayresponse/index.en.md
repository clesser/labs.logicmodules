## Description

The response filter reads response telegrams generated by the Velux KLF-200 [Gateway Connector](/en/logic.bridges.velux/gatewayconnector), filters matching messages for one device, and provides values at outputs.


Depending on module initialization order, status information of devices connected via Velux KLF-200 may only become visible at response filters in the next refresh interval (every 15 min) or after first device action. A "Stop" command for a device triggers immediate output refresh.


A URL-like [telegram syntax](/en/logic.bridges.velux/doc/syntax) is used for telegrams.

## Properties

### Inputs


| Name | Port type | Description |
| --- | --- | --- |
| Responses | Text | Receives response telegrams according to [telegram syntax](/en/logic.bridges.velux/doc/syntax). |



### Parameters


| Name | Port type | Description |
| --- | --- | --- |
| Node Identifier | Text | Identifier (name) of the device. A "/" prefix is allowed. If response filter is connected to a [Gateway](/en/logic.bridges.velux/gatewayconnector), the device name (from Velux KLF-200 device table) must always be used. For test purposes (without gateway), internal identifier (device number) can be used if prefixed with ":" (e.g., ":3"). Gateway always sends telegrams with device name. |
| Output Value Range | Selection | Defines how values "Current Value" and "Target Value" are output:*Default (0..51200)* sends raw values,*Percent (0..100)* converts raw values to percent,*Percent (100..0)* converts raw values to inverted percent. Default value: *Percent (0..100)*. |



### Outputs


| Name | Port type | Description |
| --- | --- | --- |
| Current Value | Integer | Shows current value of standard parameter of filtered device. Output follows selected output value range. |
| Current Value (%) | Percent | Shows current value of standard parameter of filtered device. Output follows selected output value range. |
| Target Value | Integer | Shows latest requested value of standard parameter of filtered device. Output follows selected output value range. |
| Target Value (%) | Percent | Shows latest requested value of standard parameter of filtered device. Output follows selected output value range. |
| Executing | Binary | Indicates whether device is currently executing movement/action to reach target value of standard parameter. |
| Error | Text | Indicates device error. *NoContact* - device is unreachable (typically no power). |
