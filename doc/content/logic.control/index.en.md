## Description

This package contains components for controlling telegrams.

## Logic modules

| Name | Description |
|---|---|
| [Blocker+](/en/logic.control/blocker) | Extension of the “Blocker” module with an additional option to send a value when a block is released. |
| [Comparer+](/en/logic.control/switch) | Extension of the “Comparer” module with parallel comparisons (numbers or text) at the outputs. |
